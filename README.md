# CV-Management-Web-Application
A PHP and MySQL web application that allows users to create, manage, and view CVs through a secure authentication system. Features include user registration, login functionality, personal CV management, and an administrative dashboard for viewing all submitted CVs.
## Overview 
This project was developed to demonstrate full-stack web development principles. The application allows users to register an account, log in securely, store CV information within a database, and access their CV details through a user-friendly interface.
The system implements a modular structure where each PHP file is responsible for a specific function, improving maintainability and code organisation.


## Features
- User Registration
- User Authentication and Login
- Session Management
- CV Creation and Storage
- Personal CV Viewing
- Dashboard for Viewing All CVs
- Individual CV Detail Pages
- Database Integration with MySQL

## Technologies Used
### Server-Side
- PHP
- MySQL
### Client-Side
- HTML5
- CSS3

---
## System Architecture

The application follows a modular PHP structure where individual files handle separate business functions.

| File | Purpose |
|--------|---------|
| `register.php` | Handles new user registration |
| `login.php` | Manages user authentication |
| `mycv.php` | Displays the logged-in user's CV |
| `dashboard.php` | Displays all CVs stored within the system |
| `cv.php` | Shows detailed information for individual CVs |

---

## Database Functionality

The MySQL database stores user CV information, including:

- Personal Information
- Educational Background
- Additional CV Details

The application uses PHP to interact with the database and perform data retrieval and storage operations.
